# CircleFound MVP

Static launch site for the Portland–Vancouver founding cohort.

## Launch flow

1. Applicant completes the Belonging Map intake.
2. FormSubmit emails the application to darnley.weekes@gmail.com.
3. Jarvis reviews fit and replies with a secure $9 Stripe Payment Link.
4. Paid members are placed into a 4–6 person micro-circle.

## Deploy

Deploy this folder to Vercel as a static project.

## Form activation

The first test submission triggers a FormSubmit confirmation email. Confirm it once before public promotion.
